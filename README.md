## Java Advance Software Engineering

[Repo Link](https://github.com/mrthetkhine/AdvancedSEBatch7)

Practice code for the Advanced Software Engineering course, written in Java.

### Topics

- **OOP** – encapsulation, inheritance, polymorphism, dependency inversion
- **Concurrency** – threads, mutual exclusion, deadlock
- **Design Patterns**
  - Creational: Singleton, Factory, Abstract Factory, Builder, Prototype
  - Structural: Adapter, Bridge, Composite, Decorator, Facade, Flyweight, Proxy
  - Behavioral: Chain of Responsibility, Command, Iterator, Mediator, Memento, Observer, State, Strategy, Template Method

### Requirements

- JDK 25
- Maven

### Run

```bash
mvn compile
```

Then run any `*Demo` class (e.g. `designpattern/observer/ObserverDemo.java`) from your IDE.
